# expert — второе мнение от Astra High в Codex

`$expert` — персональный навык для Codex. Он подключает **GPT-6 Astra с уровнем рассуждения High**, чтобы независимо проверить текущее решение, план, анализ или код.

Основную работу можно вести с Sol или Luna и вызывать эксперта в тот момент, когда нужна дополнительная проверка. После консультации основной агент показывает заключение, добавляет свою реакцию и останавливается. Дальнейшие действия определяет пользователь.

## Быстрый старт

После установки отправьте в текущем чате Codex:

```text
$expert
```

Эксперт проверит текущий обсуждаемый вопрос и последнее относящееся к нему решение. Чтобы сузить проверку, добавьте вопрос:

```text
$expert проверь, правильно ли агент определил причину ошибки
```

Ещё несколько примеров:

```text
$expert оцени предложенную архитектуру и укажи существенные риски
$expert проверь расчёт и исходные предположения
$expert сравни два варианта из предыдущего ответа
$expert проверь изменения в коде: нет ли пропущенного сценария
```

Навык запускается только по явному обращению пользователя. Сложная задача сама по себе не должна вызывать консультацию.

## Как это работает

1. Основной агент приостанавливает исходную задачу и определяет предмет проверки.
2. Он готовит задание эксперту: цель, ограничения, значимые реплики пользователя, проверяемое решение, исходные материалы и результаты проверок. Факты отделяются от предположений и неизвестного.
3. Запускается один отдельный подагент с такими параметрами:

   ```json
   {
     "task_name": "expert_review",
     "fork_turns": "none",
     "model": "gpt-6-astra",
     "reasoning_effort": "high",
     "message": "Задание и контекст для независимой проверки"
   }
   ```

4. Эксперт изучает материалы и возвращает оценку, обоснованные замечания, рекомендуемый следующий шаг и ограничения проверки.
5. Основной агент показывает отдельный блок «Заключение эксперта — Astra High», затем «Реакцию основного агента» и завершает ответ.

Заключение по умолчанию передаётся полностью. При необходимом сокращении агент должен обозначить его и сохранить существенные замечания и оговорки.

Эксперт может подтвердить исходное решение. Обязательного поиска ошибок или согласия между агентами нет. Если основной агент не согласен с экспертом, он должен объяснить основания.

Для применения рекомендаций отправьте следующее сообщение, например:

```text
Примени рекомендации эксперта и проверь результат.
```

Это уже отдельное поручение. Сам вызов `$expert` не запускает исправления.

## Требования и ограничения

- Нужна среда Codex с доступным `collaboration.spawn_agent` и возможностью выбрать `gpt-6-astra` с `reasoning_effort: high`. Сам файл навыка не добавляет инструменты и доступ к моделям.
- В реализации используется `fork_turns: none`: полная история чата автоматически не наследуется. Эксперт получает подготовленный основным агентом контекст и материалы, которые может прочитать своими инструментами.
- Если существенные данные отсутствуют, это должно быть явно отмечено. Скилл не гарантирует восстановление старых сообщений или материалов, которых уже нет в контексте.
- Эксперт работает по инструкции только на чтение: без изменения файлов, установки зависимостей, действий во внешних системах и запуска других агентов. Это ограничение поведения; отдельную техническую песочницу навык не создаёт.
- Один вызов означает одну консультацию. Автоматической подмены модели, повторного запуска после ошибки или дополнительных раундов нет.
- Если нужный инструмент или модель недоступны, основной агент сообщает, что консультация не состоялась. Собственное мнение нельзя выдавать за ответ Astra.
- Указанная модель подтверждается параметрами вызова и доступными метаданными. Независимой проверки внутренней маршрутизации платформы здесь нет.
- Консультация использует дополнительные ресурсы модели. Доступность, задержка и учёт использования зависят от вашей среды и аккаунта.

Это локальный навык. Репозиторий хранит его инструкции и документацию; он не содержит серверного приложения, API-ключей или истории ваших чатов.

## Установка

### Через Codex

Попросите Codex использовать встроенный установщик навыков:

```text
Используй $skill-installer: установи навык из репозитория
https://github.com/antoshatitov/expert-skill, путь skills/expert.
```

Для стандартной установки со встроенным `skill-installer` можно вызвать его скрипт напрямую:

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-installer/scripts/install-skill-from-github.py" \
  --repo antoshatitov/expert-skill \
  --path skills/expert
```

Расположение встроенного скрипта зависит от установки Codex. Если его нет по этому пути, используйте запрос установщику или ручной способ ниже. Если навык с таким именем уже установлен, не перезаписывайте его вслепую: сначала сравните версии и сохраните свои изменения.

### Вручную на macOS или Linux

Этот способ удобен для обновлений: персональный каталог содержит ссылку на навык в Git-репозитории.

```bash
mkdir -p "$HOME/Codex"
git clone https://github.com/antoshatitov/expert-skill.git "$HOME/Codex/expert-skill"
mkdir -p "$HOME/.agents/skills"
test ! -e "$HOME/.agents/skills/expert" && \
  test ! -L "$HOME/.agents/skills/expert" && \
  ln -s "$HOME/Codex/expert-skill/skills/expert" "$HOME/.agents/skills/expert"
```

Команды рассчитаны на новую установку. Если каталог репозитория уже существует, используйте его или выберите другой путь. Проверки `test` останавливают создание ссылки, если `~/.agents/skills/expert` уже занят файлом, каталогом или ссылкой. В таком случае сначала сравните существующую установку с новой и сохраните личные изменения.

Вместо `git clone` при настроенном GitHub CLI можно использовать:

```bash
gh repo clone antoshatitov/expert-skill "$HOME/Codex/expert-skill"
```

`~/.agents/skills` — персональный каталог навыков из актуальной документации Codex. Встроенный установщик в некоторых поставках использует `${CODEX_HOME:-$HOME/.codex}/skills`. Не создавайте независимые копии в обоих местах без необходимости: их содержимое может разойтись. Для совместимости можно использовать ссылку на один и тот же источник.

После обнаружения персональный навык доступен в разных проектах этого пользователя на данном компьютере. Он не переносится автоматически на другой компьютер или удалённую среду: там потребуется установка.

Codex обнаруживает новые навыки автоматически. Если `expert` не появился в выборе навыков, перезапустите приложение. Для проверки попробуйте в чате Codex:

```text
$expert проверь последнее предложенное решение
```

Способ выбора навыка в интерфейсе зависит от версии приложения. В этой реализации имя навыка — `expert`, обращение — `$expert`.

## Обновление и восстановление

При ручной установке со ссылкой обновите локальный репозиторий:

```bash
git -C "$HOME/Codex/expert-skill" pull --ff-only
```

После обновления ссылка ведёт на новые файлы. Если Codex продолжает использовать старую версию, перезапустите его.

Если навык установлен копированием через установщик, обновление клона само по себе не обновляет установленную копию. Сравните её с `skills/expert`, сохраните личные изменения и обновите файлы установленного навыка через Codex.

Для восстановления на другом компьютере клонируйте этот репозиторий и повторите установку. Для работы навыка нужны только два файла в каталоге `skills/expert`:

```text
skills/expert/
├── SKILL.md
└── agents/
    └── openai.yaml
```

GitHub хранит только отправленные коммиты. Локальные изменения нужно отдельно закоммитить и запушить, чтобы они тоже сохранились в репозитории. Установленная копия не синхронизируется с GitHub автоматически.

## Структура репозитория

```text
expert-skill/
├── README.md                     # Установка, использование и ограничения
└── skills/
    └── expert/
        ├── SKILL.md              # Рабочие инструкции основному агенту и эксперту
        └── agents/
            └── openai.yaml       # Название в интерфейсе и явный режим вызова
```

`allow_implicit_invocation: false` в `openai.yaml` запрещает автоматический выбор навыка по совпадению темы. Рабочие правила консультации находятся в `SKILL.md`.

Навык можно распространять отдельным каталогом. В этом репозитории он не упакован в плагин и не опубликован в каталоге плагинов.

## Проверка работы

Структуру навыка можно проверить штатным валидатором Codex. Для него нужен Python с установленным PyYAML:

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-creator/scripts/quick_validate.py" \
  skills/expert
```

Запускайте команду из корня репозитория. Если встроенный скрипт находится в другом месте, используйте фактический путь из вашей установки Codex. Проверка структуры не доказывает доступность Astra или правильность заключений.

Для ручной проверки поведения подойдут такие сценарии:

| Сценарий | Ожидаемый результат |
| --- | --- |
| Трудная задача без обращения к `$expert` | Консультация сама не запускается |
| Цена 100 выросла на 20%, затем снизилась на 20%; агент утверждает, что снова получилось 100 | Эксперт показывает расчёт: итог 96 |
| Агент утверждает, что `7 * 2` в Python равно `14` | Эксперт может подтвердить решение без искусственной критики |
| После деплоя сервис замедлился; агент без данных винит индекс | Эксперт отличает гипотезу от доказанного вывода и указывает, каких данных не хватает |
| Инструмент или нужная модель недоступны | Понятное сообщение об отказе без подмены модели и повторного запуска |
| Эксперт рекомендует изменения | Основной агент показывает заключение и свою реакцию, затем останавливается |

При первоначальной разработке состоялась пробная консультация: вызов с параметрами `gpt-6-astra` / `high` вернул ответ в основной чат. Эксперт разобрал ошибочный расчёт, подтвердил верный пример и указал на отсутствие данных для причинного вывода. Отказные сценарии проверялись разбором инструкций, без воспроизведения реального отказа модели. Это результат отдельной проверки, а не гарантия доступности модели во всех средах.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| `expert` отсутствует в списке | В каталоге навыка есть `SKILL.md`; ссылка не сломана; навык не отключён в конфигурации; приложение перечитало список навыков |
| Агент не может запустить эксперта | В текущей среде доступен `collaboration.spawn_agent`, а модель и уровень рассуждения поддерживаются |
| Эксперт не знает важную часть обсуждения | Основной агент передал нужные сообщения, исходные материалы и ограничения |
| После обновления поведение осталось старым | Обновлён именно установленный каталог или цель ссылки; нет второй устаревшей копии; Codex перезапущен |
| Агент продолжил исправлять задачу сразу после заключения | Проверьте действующую версию `SKILL.md` и явные указания пользователя: по умолчанию консультация должна завершаться остановкой |
